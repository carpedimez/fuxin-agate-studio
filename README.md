# 石里有境 · 阜新玛瑙互动工坊

在线体验：https://carpedimez.github.io/fuxin-agate-studio/

## 4K实景与预加载入境（v0.9.0）

当前首页恢复真实运动的视频，采用新找到的辽宁省政府公开玛瑙专题，源片实际2560×1440。经过轻度降噪、Lanczos 1.5倍放大和温和锐化，输出3840×2160；标注为“4K增强”，不宣称原生4K。约18.08秒的循环包含玛瑙雕件、雕刻、透雕、文创和市集，保留来源台标与角标，首尾按同一运动相位交叉淡化。原声主题片取188–224秒，约36秒，同样提供4K及1080p版本。

首页先显示内联的“石里有境”进入页，按真实传输进度更新。整段背景视频完成下载并校验字节数后转为本地Blob，再启动静音播放，确认首帧解码后才揭开首页。背景循环不再依赖播放中的网络缓冲。桌面默认4K（约20.1MB），小屏默认1080p（约8.1MB），可手动切换，已下载版本在当前页内复用。进入期间背景音乐暂不启动，入境后沿用原自动播放及手动开关逻辑。

网络失败保留进入页上的重试与先行进入选择；浏览器限制自动播放时显示“进入并播放”，不会在视频尚未播放时假装就绪。减少动态效果下使用静态封面，可主动开启视频。保留整屏弹簧翻页、3D、图鉴、形成引导、研学与作品功能。

来源：辽宁省政府网站2026年2月6日发布《玉醇秋酿 阜新秋颂》中的《阜新玛瑙——刀刃上的大地瑰宝》，来源机构为辽宁发布、辽宁卫视《黑土地》。原片、处理脚本、分镜和QA在工作区的初始材料与交付成果；站内清单为`assets/home-film/playback.json`。第三方素材使用范围仍待权利方确认，不声明为本站原创拍摄。

代码入口：`home-cinema.mjs`、`entrance-critical.css`、`music.mjs`、`index.source.html`。构建脚本将进入页CSS内联，让它在应用准备期间即可显示。4K为增强输出，源片的光学景深、运动模糊与原始细节上限仍会保留。

## 图片轮播与整屏滚动（v0.8.0）

首页背景改为四幅实景截帧循环，每张停留6.5秒，淡化切换1.1秒，图片合计187,030字节。支持暂停、上一张/下一张、圆点选图与观石/知艺/入乡主题切换。首页不再创建背景video或自动请求MP4；原声玛瑙主题片保留，按需点击播放。离开首屏、切换路由、打开主题片或页面进入后台时暂停轮播。减少动态效果与省流量时默认静态，可手动开启。

首页分为观石入境、读懂纹色、石的来历、实物图鉴、非遗手艺五个章节。滚轮、PageUp/PageDown、方向键与空白区域鼠标拖拽以阻尼弹簧动画切换；原生CSS吸附保证触摸滚动落在章节边界。长图鉴可以在章节内正常滚动，页脚可达；画布、输入框和弹窗内的操作不拦截。创作、循艺入乡与我的作品页面维持原有滚动。

代码：`home-cinema.mjs`、`page-snap.mjs`、`page-snap.css`、`index.source.html`。四图路径和对应原片时间见`assets/home-film/manifest.json`。旧背景视频文件保留兼容已缓存的历史页面，当前首页不请求它。

## 阜新玛瑙实景首页（v0.7.0）

首页采用约20.2秒的本地静音循环，以玛瑙雕件、手工雕刻、玛瑙市场与阜新水岸为内容，配合“石里有境——从一枚玛瑙，走进阜新”和创作、入乡、主题片三个入口。原3D原石移至首屏下方，实物图鉴、形成引导、纹色创作与研学内容保留。

点击“观看玛瑙主题片”打开约33.8秒的连续原声玛瑙选段。为满足主题范围，不把原片中的工业、交通及城市综合画面放入站内播放器；综合原片以署名链接提供。观影期间暂停背景音乐，关闭后仅恢复原先在播放或准备播放的音乐；原先手动暂停的音乐保持暂停。离开首页、滚出首屏或页面进入后台时暂停背景视频。减少动态效果或省流量时默认显示封面，可手动播放；视频失败也保留封面与入口。

源码：`home-cinema.mjs`、`home-cinema.css`、`index.source.html`；媒体及分镜记录：`assets/home-film`。两段本地 H.264 视频合计约9.1 MB，首屏循环约4 MB；主题片按需请求。保留公开片源的真实800×480分辨率，未宣称为高清。

影像来自国际在线2025年12月30日发布的《看见阜新：从文明摇篮到生态新城》，文/视频：阜新市委宣传部。封面为原片截帧，水岸不冒充十家子或八宝海实景。原始文件与剪辑脚本存于工作区初始材料和交付成果。第三方视频未查到明确开放许可，未标记为本站原创或CC素材；转载、剪辑及参赛使用范围仍待权利方确认。

以辽宁阜新玛瑙文化为主题的静态交互网站，面向智慧文旅与乡村振兴场景。

包含纹色分析、借色构形、手绘轮廓与刻线、三维成器、纹样与落款、文创搭配、方案导入导出、纪念海报、文化资料查询和背景音乐。

## 运行与发布

纯静态网页，HTML、CSS、JavaScript模块与素材全部在仓库内。运行已发布网页无需安装依赖，通过任意静态HTTP服务器访问 `index.html`，或在GitHub Pages设置中选择 `main` 分支及根目录发布。

为减少首次加载请求，页面使用合并后的 `site.bundle.js` 与 `site.bundle.css`。原始模块及样式仍在仓库内，页面模板为 `index.source.html`。修改源码后执行 `npm ci`、`npm run build`，提交生成文件再推送 `main` 即可更新。

内置Three.js和样本，不依赖外部CDN。原料照片、作品收藏及研学意向仅保存在当前浏览器；更换网站地址不会自动同步旧站数据，可导出完整JSON方案后在新站导入。

## 背景音乐自动播放

进入网站即准备歌曲并尝试有声播放，单曲循环。若浏览器阻止自动播放，首次点击、触摸页面或按回车/空格后尝试启动；仍可用右上角音符开关手动播放。用户主动暂停或取消加载后，其他页面操作不会重新开启音乐。刷新页面会重新尝试自动播放，音量沿用本机设置。

## 写实玛瑙形成演示（v0.5.0）

形成引导采用四幅由内置 image_gen 生成的写实地质情境，配合 WebGL 的微距视差、水面折射、光影与分镜揭示转场。支持自动演示/暂停、拖动叙事进度、阶段选择、微距细看、纹层提亮、大画面和跳过。首次提示记忆键更新为 agate-formation-intro-v2，旧版用户可看到本次重做；首页与创作页均可重看。

源码：formation.mjs、formation-cinema.mjs、formation.css。素材：assets/formation-v2，清单见 manifest.json。页面将生成情境与真实实物图鉴分开署名；未将其标记为真实标本或物理模拟。地质解释仍据 data.mjs 中的博物馆与研究综述，不设统一地质时长或阜新实物成因断言。

无 WebGL 时使用写实图片，大图加载失败时保留缩略预览与操作。减少动态效果偏好下不自动播放、不启动持续镜头运动。关闭或页面隐藏后停止动画渲染。原始 PNG 与完整生成提示词已保留在工作区“初始材料/写实形成视觉”。
